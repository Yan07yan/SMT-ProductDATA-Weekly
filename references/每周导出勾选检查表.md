# 速卖通 · 每周导出勾选检查表（周报输入）

> **用法**：每周一导出下面打勾的项，全部丢进同一个目录（即运行脚本时的 `--data` 目录），然后跟 WorkBuddy 说一句 **「跑周报」** 即可。
> 打勾 = 本周已完成导出。这张表每周通用，不用改。
> 注意：文件名必须与下表一致（脚本按文件名识别），换账号改店铺代号时改 `config.json` 的 `shop_file` / `cat_file` / `saas_shop`（不要改脚本代码）。

---

## 一、每周一必做（POP 四店：YZ3 / PHCX04 / WHDS06 / ZHHK04）

☐ **商品分析-近30天数据 ×4 店**（文件名 `YZ3-30天数据.xlsx` 等）
　→ 用途：拉「主图优化清单」（高曝光低点击）、「详情页优化清单」（有访客不成交）、「热销链接候选」
　⚠️ 导出时时间范围选 **「近30天」**，别选 7 天；sheet 名须含「汇总指标」

☐ **商品分析-上周数据 ×4 店**（文件名 `YZ3-上周数据.xlsx` 等）
　→ 用途：页4「上周卖得好的品类」+「本周上品方向」草稿（按根类目名称聚合件数/金额/占店比）
　⚠️ 导出时时间范围选 **「上周」**（或自定义最近 7 天）；缺此文件脚本自动回退 30 天文件并标⚠️

☐ **商品总数据 ×4 店**（文件名 `YZ3商品总数据.xlsx` 等）
　→ 用途：全量在线目录（动销率）、滞销品判定、物流重/运费模板/欧盟责任人筛查
　⚠️ 导出后**双击打开 → 直接保存一次**（让 Excel 把数据落盘成静态单元格），否则脚本读到的是空壳，滞销清算会"暂停"

☐ **四店「商品管理」列表导出.xls**
　→ 用途：POP 上架数量（刊登 KPI）+ 上品通过率分母（ID 差集法，不用记被拒原因）
　⚠️ 导出时勾「全部状态 / 全量」，别只导近期子集

## 二、每周一必做（全托管 CLYT1）

☐ **CLYT1全托30天数据.xlsx**
　→ 用途：全托管热销链接 / 订单（支付件数）

☐ **QTG-GLYT1 近三十天结算.xlsx**（每月有新的就更新）
　→ 用途：全托管销售额（取 `实际结算金额`；CLYT1 的 30 天数据无金额列，不能从这里取）

☐ **五店「销售额订单数据」.xls**
　→ 用途：四店 POP **销售额 KPI** + **利润率**（含 `产品总金额`/`发货产品供货价`/`发货产品数量`）

## 三、每日维护（上品台账）

☐ **刊登数量追踪.xlsx**（列：日期 / CLYT1 / YZ3 / WHDS06 / PHCX04 / ZHHK04 / 合计）
　→ 用途：刊登数量 KPI（脚本按上周窗口汇总）
　⚠️ 缺文件时脚本会自动建带表头模板，填好后重跑即可；CLYT1=全托管，其余四列=POP
　💡 也可用本 skill 的 `assets/刊登数量追踪_模板.xlsx` 复制一份开始记

## 四、每月 1 号补充

☐ **成本表（采购成本 CNY）**
　→ 用途：真实毛利率（脚本目前用订单供货价估算，待成本表可交叉验证）

☐ **全托管上架数据.xlsx**（如启用，按创建时间窗算全托上架）
　→ 用途：全托刊登数量并进来（目前以「刊登数量追踪.xlsx」为主，此文件可空）

## 五、跑完之后

→ 跟 WorkBuddy 说：**「跑周报」**
→ 自动生成《周度行动表》：公司 KPI 缺口 → 本周行动清单（主图/详情页 TOP → 上品通过率）→ 数据底稿 → 上周好品类与本周方向（页4：各店好品类+本周上品方向手填）

---

### 备注（数据边界）
- 销售额 = 四店 POP 订单月化 + 全托 30 天结算金额；POP 窗口仅几天时月化为估算，建议改导「月至今/自然月」口径直接对标。
- 商品总数据**必须打开保存一次**再丢进目录，否则是空壳（已踩过坑）。
- `_listing快照.json` 是跨周持久化的 ID 基线，**不要删**，否则通过率永远停在"基线周"。
